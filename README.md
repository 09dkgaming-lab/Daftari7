# دفتري — دفتر دين البقالة الذكي
Kotlin + Jetpack Compose + Room (SQLite) — يعمل بدون إنترنت، والنسخ السحابي عبر Firebase.

## التشغيل
1. افتح المجلد في Android Studio (Koala أو أحدث) وانتظر Gradle Sync.
2. شغّل على جوال أو محاكي (minSdk 24).

## تفعيل تسجيل الدخول بجوجل والنسخ السحابي
1. أنشئ مشروع في https://console.firebase.google.com وأضف تطبيق أندرويد باسم الحزمة `com.daftari.app`.
2. أضف بصمة SHA-1 (من Android Studio: Gradle > signingReport).
3. فعّل Authentication > Google، وأنشئ قاعدة Firestore.
4. استبدل `app/google-services.json` (الموجود مجرد placeholder) بالملف الذي ينزّله Firebase.
5. قواعد Firestore المقترحة:
   `match /backups/{uid} { allow read, write: if request.auth.uid == uid; }`

بعد تسجيل الدخول: كل دين أو تسديد يُرفع تلقائياً كنسخة احتياطية عند توفر النت، ويمكن الاسترجاع من الإعدادات.

## ما هو منفّذ
- زبائن، دين، تسديد (كل المحافظ)، حاسبة داخلية (+ − × ÷ مسح تطبيق) وحاسبة عامة
- كشف حساب بفلتر التاريخ، إرسال صورة / PDF / نص عبر واتساب
- رسالة واتساب جاهزة عند كل دين وتسديد، وزر التذكير، والمتأخرون (+15 يوم) بالأحمر
- نجوم السمعة، تقارير (مقبوض اليوم حسب الطريقة، أكثر مديون، أكثر التزاماً)
- نسخ احتياطي: سحابي (جوجل) أو تصدير واتساب
- عداد التجربة المجانية 7 أيام

## المرحلة التالية (غير منفّذة)
- تفعيل الاشتراك بالكود، وباقات الرسائل (يحتاج خادم للتحقق من الأكواد)
- WhatsApp Cloud API لإرسال الرسائل تلقائياً
- شعار البقالة داخل صورة الكشف
